## 🚀 Projects

### 🫁 [PulmoCare — Multimodal AI Diagnostic System](https://github.com/bhargavbahirat/Pulmocare)

**Tech Stack:** *Python · TensorFlow · Scikit-learn · Librosa · OpenCV · Flask · MongoDB · Next.js*

An advanced AI-powered web platform for early detection and severity prediction of **COPD** and **Pneumonia**, built as a Final Year Project.

- 🩻 **Medical Imaging** — CNN (ResNet/VGG) for chest X-ray & CT scan classification
- 🎙️ **Respiratory Audio** — 1D-CNN + BiLSTM for breathing sound analysis using MFCCs
- 📋 **Clinical Data** — Random Forest on questionnaire scores (mMRC, CAT, HAD, SGRQ)
- 🔀 **Multimodal Fusion** — Weighted ensemble combining all three modalities
- 📄 **Output** — Disease label + GOLD severity stage + confidence score + PDF report
- 🔒 **Security** — AES-256 encryption, JWT auth, role-based access (Patient / Doctor / Admin)
